Daytona 675 K-line diagnostics

No serial port found. Plug the cable into USB (on Windows the FTDI driver may need installing: see the README) and it will show up here by itself.

Getting started

  1. Plug the cable into the bike's diagnostic connector (under the seat, in front of the fusebox) and into USB.
  2. Turn the ignition on and set the kill switch to run. Engine off is fine; a battery tender helps on long sessions.
  3. Pick the cable's port at the top (the FTDI one) and press Connect. The Daytona answers only about one try in three, so this can take up to a minute.
Once connected the dashboard and the switch watcher start by themselves. Fault codes, the dials and recordings need nothing else. The switch names, battery, gear, graphs of the injection pulse and the output tests need the ECU unlock (optional, see the README).

Dashboard

Standard OBD-II data from the ECU: RPM, speed, throttle, manifold pressure, temperatures, load, timing, fuel trim and fuel system status. Battery and gear need the ECU unlock.

Switches

Output tests (optional)

Needs the ECU unlock, not available.
These tests command the ECU to drive one output briefly (the tach needle, the cooling fan, the fuel pump, the idle speed stepper, the purge valve, secondary air, the air flap or the exhaust valve) so you can check that it works. It is the only part of this tool that makes the bike move or run parts, and nothing else is ever commanded. They are off until you enable them here, and enabling lasts for this page session only.

Graphs

Fuel and engine graphs, drawn from the dashboard while it runs and from the recorder while recording (the injection pulse, fuel pump and tip-over need the ECU unlock). A saved recording opens here as the same graphs.

Fuel map

Record

Records the gauges, switches and analog values together, with a time stamp for every sample, into one CSV in the logs folder. Use it to catch the bike starting and then dying. The dashboard pauses while recording. Works locked too, with the OBD values only.

Find more IDs (advanced)

    
Needs the ECU unlock, not available.

    

      
Asks the ECU about every 0x22 id in a range and lists the ones it answers (read-only: nothing else is sent). The default range takes a couple of minutes. To find what an id means: take Snapshot A, do something to the bike (lift the sidestand, flip the kill switch, tilt it), take Snapshot B and see which ids changed.
